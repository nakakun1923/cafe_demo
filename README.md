# cafe&BAR Caprice

静的カフェデモサイトです。

- 公開TOP・メニュー: index.html / menu.html。以前のデザイン・写真・文章を維持しています。
- コンセプト案: concept/index.html / concept/menu.html。「少しラフで、きちんと清潔」な地域の食堂兼カフェとして、ひと目で伝わる構成に再設計した案です。生成り色と焦げ茶の木、喫茶店らしい深緑（標準テーマ「喫茶」。実店舗の内装写真から配色・葉柄・丸い吊りランプのモチーフを起こしています）、丸ゴシック、すべて日本語表記。コンセプト案であることの注記はヒーロー直下に一か所だけ置いています。
  - カラー切り替え: 右下の「カラー」ボタンで配色を比較できます（選択は保存され、index/menu間で引き継がれます）。URLに `?theme=` を付けても指定できます: `kissa`（標準）/ `terracotta` / `sage` / `indigo` / `mustard` / `sakura` / `sky`。
  - 構成: ヒーロー（写真と一言）→ Capriceの使いかた（ひるごはん・ひと息・夜のこと）→ お店のこと → 写真（2枚）→ アクセス。メニューは別ページ（写真で目指す姿を紹介。品目・価格は載せていません）。
  - 写真は重複させず、写真を押すと拡大表示（キーボード・Escape・動きを減らす設定に対応）。

- コンセプト案2: concept2/index.html / concept2/menu.html。案1の構成・文章はそのままに、公開TOPの落ち着いた雰囲気（濃いエスプレッソ色のヘッダー・フッター、生成り色の紙面、真鍮色の細い罫線、Noto Serif JPの見出し、直角に近い形・細い罫線・矢印付きテキストリンク）を取り入れた案です。ヒーローは湯気の立つコーヒーの一杯、店内写真は吊りランプとカウンターを寄せたトリミングにして、明るい住宅展示場のような印象を避け、全写真に同じ落ち着いた色調を当てています。カラー切り替えはなく、配色は1つです。

- コンセプト案3: concept3/index.html / concept3/menu.html。案2の落ち着いた見た目はそのままに、飾りを減らして店主の言葉に近い文面へ整えた案です。ヒーロー（「とりあえず、ここにしよう。」）→ ご近所のいつもの店に → Capriceの一日（おひる・ごご・よる）→ メニューへの案内 → 話すことが、きっかけになる → アクセス → 注記。ヒーローと一日の終わりからメニューページへ進めます。

どの案も、ヘッダーの順序とリンク先は共通で、フッターから公開TOPとコンセプト案を行き来できます。コンセプト案にはnoindexを設定しています。
